# Lei Leonova — personal site

Static, responsive English-language portfolio. No build step or external runtime dependencies.

## Publish to GitHub Pages
1. Create a public repository named `YOURUSERNAME.github.io` (or any repository for a project site).
2. Upload `index.html` and the `assets` directory, preserving paths.
3. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Wait for GitHub Pages to publish, then visit the URL displayed in Pages settings.
